# iron-quest

¿Qué incluye?
- Tres clases: Guerrero (fuerza), Pícaro (agilidad) y Paladín (estabilidad).
- 24 misiones diferentes, distribuidas entre las tres rutinas.
- Experiencia y niveles: 10 XP por ejercicio y hasta 20 XP por jefe final.
- Temporizador interactivo de trabajo y descanso.
- Historial de entrenamientos con fecha, ejercicios y XP.
- Logros desbloqueables y estadísticas.
- Guardado automático en el navegador, con exportación e importación de datos.

Importante: esta primera versión guarda la información localmente, por lo que todavía no sincroniza el progreso entre dispositivos. Incluye copias de seguridad en JSON para trasladar tus entrenamientos.
